# LightTable 0.7.7

Existing photos may look different after this update. The tone stage now works in linear light with a highlight shoulder, and RAW photos you have never edited open with the new LightTable Standard look. DNG camera profiles now apply their color and forward matrices with dual-illuminant blending. Review your existing edits before making final exports.

Grid filtering, sorting and Select All now run on the server, and you can reverse the sort direction and compare two photos side by side. Collections can be nested, renamed and reordered, Quick Collection is on Cmd+B, and Locate reconnects unavailable folders and missing photos.

Editing adds mask duplication, feather for linear gradients, named snapshots and guided upright. Export adds custom sizing (long or short edge, fit within a box, megapixels, percent, no enlargement, pixels per inch), output sharpening, a JPEG file size limit and a TIFF bit depth choice. Full-resolution merges now check available memory first.

Subject and Person masks now work on Windows and Linux, and learned denoise ships in the Windows and Linux packages. Lens profiles turn on automatically when the match is confident, chromatic aberration has its own controls, and the importer now brings in folder sidecars from the native app, including nested folders. Scanning and export encoding are faster, and Windows and Linux receive the interactive preview without JPEG compression.

## Installation

Download the asset for your platform from this release or follow the [installation pages](https://lighttable.app/).

- **Windows x64:** use the setup executable for installation or the ZIP for portable use. Direct installer updates belong to the app; Scoop updates belong to Scoop. For Scoop: `scoop bucket add lighttable https://github.com/reville/scoop-lighttable`, then `scoop install lighttable`.
- **Linux x86_64:** use the portable archive on Ubuntu 24.04 or newer. Follow the [Linux installation instructions](https://lighttable.app/linux.html) for supported packages and update ownership.
- **macOS Apple silicon:** the separate [0.7.7-beta.1 release](https://github.com/reville/lighttable-digital-darkroom/releases/tag/macos-v0.7.7-beta.1) requires macOS 14 or newer. It is ad-hoc signed and is not notarized. After the first blocked launch, use System Settings > Privacy & Security > Open Anyway. For Homebrew: `brew install --cask reville/lighttable/lighttable@beta`. Use Homebrew to update a Homebrew installation; manual DMG installations require manual replacement.
- **npm CLI installer:** `npm install -g lighttable-digital-darkroom@0.7.7`, then `lighttable install`. See [CLI installation](https://lighttable.app/windows.html) for the desktop installation options.

Physical Windows GPU/display coverage remains experimental. This release does not establish native Windows ARM64 support or a new Store publication.
