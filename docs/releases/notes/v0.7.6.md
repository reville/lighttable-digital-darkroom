# LightTable 0.7.6

Existing photos may look different after this update. The Whites control now brightens highlights when moved to the right, and saved edits are migrated to the corrected direction. This release also corrects GPU print preflash. Review your existing edits before making final exports.

This release adds dust removal, brush Remove, lens blur, curve eyedroppers, color samplers, borders, contact sheets, and local hair segmentation for People masks. Heal and Clone previews stay live on supported macOS editing paths. RAW lens-profile defaults, chromatic aberration controls, and capture white balance have also been improved.

Photo navigation can show a draft first frame while the accurate preview loads. Export encoding, photo scanning, and engine warm-up have been updated to reduce waiting. The Apple Photos picker marks photos that are already imported, and viewing imported photos clears filters that could hide them.

## Installation

Download the asset for your platform from this release or follow the [installation pages](https://lighttable.app/).

- **Windows x64:** use the setup executable for installation or the ZIP for portable use. Direct installer updates belong to the app; Scoop updates belong to Scoop. For Scoop: `scoop bucket add lighttable https://github.com/reville/scoop-lighttable`, then `scoop install lighttable`.
- **Linux x86_64:** use the portable archive on Ubuntu 24.04 or newer. Follow the [Linux installation instructions](https://lighttable.app/linux.html) for supported packages and update ownership.
- **macOS Apple silicon:** the separate [0.7.6-beta.1 release](https://github.com/reville/lighttable-digital-darkroom/releases/tag/macos-v0.7.6-beta.1) requires macOS 14 or newer. It is ad-hoc signed and is not notarized. After the first blocked launch, use System Settings > Privacy & Security > Open Anyway. For Homebrew: `brew install --cask reville/lighttable/lighttable@beta`. Use Homebrew to update a Homebrew installation; manual DMG installations require manual replacement.
- **npm CLI installer:** `npm install -g lighttable-digital-darkroom@0.7.6`, then `lighttable install`. See [CLI installation](https://lighttable.app/windows.html) for the desktop installation options.

Physical Windows GPU/display coverage remains experimental. This release does not establish native Windows ARM64 support or a new Store publication.
