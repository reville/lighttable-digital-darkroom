# LightTable 0.7.10

This point release delivers noticeable launch and export performance gains on macOS, automatic interface recovery after graphics or memory faults, cross-platform access to update checks, and hardened release gates.

## What's New

- **Faster startup and export on macOS:** Shipped application bundles now read pre-compiled Python bytecode directly on macOS rather than recompiling imported modules on every launch. Server initialization after first launch drops from ~1.1 s to 0.44 s, initial photo presentation drops from ~1.3 s to 0.65 s, and film-off export of intermediate JPEGs drops from 2.5 s to 1.0 s steady state.
- **Interface recovery after unexpected exits:** When WebKit's web view content process terminates due to system memory pressure or a GPU fault, LightTable now reloads the interface automatically (up to 3 times per minute). If repeated failures exceed the budget, an alert provides clear guidance to reload manually via **Help ▸ Diagnostics ▸ Reload Interface** or submit a diagnostic report via **Help ▸ Report a Problem…**.
- **Universal update checks:** "Check for Updates…" is now always available in the macOS application menu (connecting directly to Sparkle when supported, or opening Settings), in the in-app **Help** panel header across macOS, Windows, and Linux, and via the `Ctrl+,` (or `Cmd+,`) shortcut to jump straight to Settings.
- **Hardened release acceptance:** Product journey smoke tests now inspect crash ledgers, diagnostic incident stores, and launch headers to ensure that unexpected server exits fail the release gate even if a background process auto-restarts.

## Installation

Download the asset for your platform from this release or follow the [installation instructions](https://lighttable.app/):

- **Windows x64:** use the setup executable for installation or the ZIP for portable use. Direct installer updates belong to the app; Scoop updates belong to Scoop. For Scoop: `scoop bucket add lighttable https://github.com/reville/scoop-lighttable`, then `scoop install lighttable`.
- **Linux x86_64:** use the portable archive on Ubuntu 24.04 or newer. Follow the [Linux installation instructions](https://lighttable.app/linux.html) for supported packages and update ownership.
- **macOS Apple silicon:** the separate [0.7.10-beta.1 release](https://github.com/reville/lighttable-digital-darkroom/releases/tag/macos-v0.7.10-beta.1) requires macOS 14 or newer. For Homebrew: `brew install --cask reville/lighttable/lighttable@beta`. Use Homebrew to update a Homebrew installation; manual DMG installations require manual replacement.
- **npm CLI installer:** `npm install -g lighttable-digital-darkroom@0.7.10`, then `lighttable install`. See [CLI installation](https://lighttable.app/windows.html) for the desktop installation options.

Physical Windows GPU/display coverage remains experimental. This release does not establish native Windows ARM64 support or a new Store publication.
