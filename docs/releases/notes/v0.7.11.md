# LightTable 0.7.11

This point release adds a direct way for Windows users to review LightTable in the Microsoft Store and a restrained, dismissible reminder after successful exports. It also includes release-process fixes merged since 0.7.10.

## What's New

- **Microsoft Store review action on Windows:** Open Help and choose **Write a Microsoft Store review…** to reach LightTable's Store review page. After three successful exports over at least seven days, LightTable may show a small review reminder. **No thanks** dismisses future reminders; the Help action remains available. The reminder is not shown during an update offer or another dialog.
- **Release maintenance:** The build fingerprint now accepts changes to the macOS update-feed URL without forcing an unnecessary full rebuild. Release-process documentation clarifies the GitHub Latest badge and local checkout synchronization.

## Installation

Download the asset for your platform from this release or follow the [installation instructions](https://lighttable.app/):

- **Windows x64:** use the signed setup executable for installation or the ZIP for portable use. Direct installer updates belong to the app; Scoop updates belong to Scoop. For Scoop: `scoop bucket add lighttable https://github.com/reville/scoop-lighttable`, then `scoop install lighttable`.
- **Linux x86_64:** use the portable archive on Ubuntu 24.04 or newer. Follow the [Linux installation instructions](https://lighttable.app/linux.html) for supported packages and update ownership.
- **macOS Apple silicon:** the separate [0.7.10-beta.1 release](https://github.com/reville/lighttable-digital-darkroom/releases/tag/macos-v0.7.10-beta.1) requires macOS 14 or newer. For Homebrew: `brew install --cask reville/lighttable/lighttable@beta`. Use Homebrew to update a Homebrew installation; manual DMG installations require manual replacement.
- **npm CLI installer:** `npm install -g lighttable-digital-darkroom@0.7.11`, then `lighttable install` after the package's publication is confirmed. See [CLI installation](https://lighttable.app/windows.html) for desktop installation options.

Physical Windows GPU/display coverage remains experimental. The Microsoft Store has its own review and update process; this GitHub release does not by itself update the Store listing.
