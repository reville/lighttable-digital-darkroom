# LightTable 0.7.9

This point release adds optional, opt-in crash reporting and resolves several stability and startup issues across all platforms.

## What's New

- **Opt-in crash reporting:** Released builds now ask once on first launch whether you would like to help improve LightTable by sending anonymous crash reports. If you agree, technical details about crashes (app version, OS, hardware architecture, and crash stack traces in LightTable's own code) are sent to help us identify and fix bugs. Reports never include photos, photo metadata, file paths, folder names, catalog contents, or personal identifiers. You can turn crash reporting on or off at any time in **Settings → General**.
- **Metadata stability:** Resolved a concurrency crash in `exiv2` when multiple threads read image metadata simultaneously by ensuring thread-safe initialization up front.
- **Startup and shutdown reliability:** Fixed a slow startup hang during system font scanning, eliminated a race condition during server shutdown, and prevented transient connection drops during initial app launch.
- **Mac packaging improvements:** Cleaner DMG disk image contents without obsolete launch warnings, and enhanced reliability in release orchestration and distribution feeds.

## Installation

Download the asset for your platform from this release or follow the [installation instructions](https://lighttable.app/):

- **Windows x64:** use the setup executable for installation or the ZIP for portable use. Direct installer updates belong to the app; Scoop updates belong to Scoop. For Scoop: `scoop bucket add lighttable https://github.com/reville/scoop-lighttable`, then `scoop install lighttable`.
- **Linux x86_64:** use the portable archive on Ubuntu 24.04 or newer. Follow the [Linux installation instructions](https://lighttable.app/linux.html) for supported packages and update ownership.
- **macOS Apple silicon:** the separate [0.7.9-beta.1 release](https://github.com/reville/lighttable-digital-darkroom/releases/tag/macos-v0.7.9-beta.1) requires macOS 14 or newer. For Homebrew: `brew install --cask reville/lighttable/lighttable@beta`. Use Homebrew to update a Homebrew installation; manual DMG installations require manual replacement.
- **npm CLI installer:** `npm install -g lighttable-digital-darkroom@0.7.9`, then `lighttable install`. See [CLI installation](https://lighttable.app/windows.html) for the desktop installation options.

Physical Windows GPU/display coverage remains experimental. This release does not establish native Windows ARM64 support or a new Store publication.
